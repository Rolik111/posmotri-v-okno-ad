# Посмотри в окно

Учебная страница для поиска и просмотра видео из разных городов. Стилизация форм, списка роликов, состояний загрузки и ошибок по макету. HTML и JavaScript взяты из стартового шаблона задания.

Репозиторий: https://github.com/Rolik111/posmotri-v-okno-ad

Для просмотра откройте `index.html` через локальный HTTP-сервер. Поиск видео требует доступности внешнего API, указанного в скрипте проекта.
